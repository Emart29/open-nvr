# Format: kind|model|min_ram_gb|tested|speed|summary
#   kind      llm | vlm

#   tested    yes = exercised with THIS agent (tool prompts, voice loop)
#             no  = known-good model, but not validated with this agent
#   speed     relative answer latency on matched hardware
#   summary   one line of honest editorial: what it is actually good at
#
# Ordering within a kind = menu order. Keep "tested" entries first.
